# To-Do List

A simple command-line To-Do List application built with Python.

## Features

- Add tasks with a name and description
- View tasks
- Remove tasks
- Exit the application
- Basic input validation and user feedback

## Requirements

- Python 3.x
- No external dependencies

## How to Run

Clone or download the project, navigate to the project directory, and run:

```bash
python main.py
```

## Usage

The application provides a menu with the following options:

1. Add a task
2. View tasks
3. Remove a task
4. Exit

Follow the prompts displayed in the terminal to manage your tasks.

## Current Limitations

- Tasks are not permanently stored.
- Task names are used to identify tasks and therefore should be unique.

## Future Improvements

Potential improvements may include:
