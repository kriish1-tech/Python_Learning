# Simple Calculator

A simple command-line calculator built with Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Continuous calculations until the user exits

## Requirements

- Python 3.x
- No external dependencies

## How to Run

Navigate to the project directory and run:

```bash
python main.py
```

## Usage

The calculator supports the following operations:

```text
+
-
*
/
exit
```

When prompted:

1. Enter an operation.
2. Enter the first number.
3. Enter the second number.
4. The calculator displays the result.
5. Enter `exit` to quit the program.

## Example

```text
Welcome to the Simple Calculator!

Enter an operation (+, -, *, /) or 'exit' to quit: +
Enter the first number: 10
Enter the second number: 5
The result of addition is: 15.0
```

## Current Limitations

- Only basic arithmetic operations are supported.
- Calculations are performed one operation at a time.
- Invalid numeric input is not currently handled.
- There is no calculation history.
